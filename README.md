# Photobooth Van

A bilingual WordPress website for an Athens-based team that offers photo and video booths for weddings, parties and corporate events.

[Explore the live website in English ↗](https://photoboothvan.gr/en/)

## The brief

Someone planning an event needs to answer two questions: which booth fits the occasion, and is it available on the day? I designed the site around that journey, from exploring the five booth options to requesting a quote with the event date, location and preferred service.

## My role

I designed and launched the Greek and English versions of the site using WordPress and Elementor. I organised the service pages, wrote custom HTML and CSS, and adapted the layouts for desktop and mobile. After launch, I set up Google Analytics 4 events to track contact form submissions and WhatsApp clicks.
